# unity_vr_input

Projekt generowany maszynowo za pomocą Claude Code i modelu Opus 5.5.

Demo wejść VR (kontrolery, dłonie, gesty, Interaction SDK) dla Meta Quest 3S w Unity 6.3 LTS (6000.3.24f1).

Instrukcja konfiguracji, Build & Run przez USB, debugowania i obsługi: [INSTRUKCJA.md](INSTRUKCJA.md)
